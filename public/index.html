💡 Theory Quick Reference

Cache HIT: Data is read directly from memory (RAM) in sub-millisecond to ~10ms speed.

Cache MISS: Server executes MongoDB query over socket, then stores response in RAM with a 60s TTL.

Cache Invalidation: On any POST/PUT/DELETE, keys are evicted immediately to eliminate stale reads.
